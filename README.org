#+title: pgsql.el

[[https://melpa.org/#/pgsql][file:https://melpa.org/packages/pgsql-badge.svg]]

A native PostgreSQL wire-protocol (v3) client written in Emacs Lisp, with no =psql= subprocess, JDBC bridge, or third-party runtime dependencies. Requires Emacs 29.1 or newer.

* Scope

=pgsql.el= handles protocol work only: simple and parameterized queries, asynchronous execution, =COPY ... TO STDOUT= streaming, and query cancellation. Higher-level features like query consoles, result grids, completion, or connection pooling belong in applications built on top of it (such as [[https://github.com/LuciusChen/clutch][Clutch]]).

** Relationship to pg.el

MELPA already has [[https://github.com/emarsden/pg-el][pg.el]], which is mature and much broader (including Unix-domain sockets, idle LISTEN/NOTIFY handling, extensible type decoders, and wide server coverage). If you need those features, use =pg.el=.

=pgsql.el= is aimed at callers that want a narrower, predictable protocol library: zero external dependencies, one request in flight per connection, every request drained cleanly through =ReadyForQuery=, explicit =pgsql-null= distinct from boolean =nil=, server-reported transaction state, and cancellation that leaves the connection synchronized before reuse.

* Installation

Install from [[https://melpa.org/#/pgsql][MELPA]] with =M-x package-install RET pgsql RET=, or via =use-package=:

#+begin_src emacs-lisp
(use-package pgsql
  :ensure t)
#+end_src

Or from a source checkout:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/pgsql.el")
(require 'pgsql)
#+end_src

* Usage

** Connecting and TLS

Connect with keyword arguments and always disconnect when done:

#+begin_src emacs-lisp
(let ((conn (pgsql-connect :host "127.0.0.1"
                           :port 5432
                           :user "app"
                           :password "secret"
                           :database "app"
                           :sslmode 'prefer)))
  (unwind-protect
      (pgsql-result-rows
       (pgsql-exec conn "SELECT current_database()"))
    (pgsql-disconnect conn)))
#+end_src

=:sslmode= accepts =disable=, =prefer=, =require=, and =verify-full=. Under =prefer=, plaintext fallback happens only when the server explicitly rejects SSL; TLS handshake and certificate errors are always signaled. SCRAM-SHA-256 authentication uses PostgreSQL-compatible SASLprep (with raw-password fallback when input cannot be prepared).

Connections are opaque. Inspect them with =pgsql-user=, =pgsql-host=, =pgsql-port=, =pgsql-database=, =pgsql-live-p=, =pgsql-busy-p=, =pgsql-transaction-status=, and =pgsql-parameter=. =pgsql-connect-timeout= bounds the TCP, TLS, and auth sequence; =pgsql-read-timeout= is an idle timeout that resets as response chunks arrive. Both can be updated per connection with =pgsql-set-connect-timeout= and =pgsql-set-read-timeout=.

** Parameterized queries and type decoding

Use =pgsql-exec-params= for extended-protocol queries. Pass each parameter as =(value . type-name)=. Use =pgsql-null= for SQL NULL; Lisp =nil= means PostgreSQL boolean =false=:

#+begin_src emacs-lisp
(pgsql-exec-params
 conn
 "SELECT $1::int4, $2::text, $3::boolean, $4::int4[]"
 (list (cons 42 "int4")
       (cons pgsql-null "text")
       (cons nil "bool")
       (cons (vector 1 pgsql-null 3) "int4[]")))
#+end_src

Built-in type names are sent as Parse OIDs; unknown, extension, or domain names still act as local encoding hints while PostgreSQL infers the server type.

Results expose =pgsql-result-columns=, =pgsql-result-rows=, =pgsql-result-command-tag=, =pgsql-result-affected-rows=, and =pgsql-result-notices= (such as =RAISE NOTICE= output, oldest first). Column metadata uses =pgsql-column-name=, =pgsql-column-type-oid=, and =pgsql-column-type-name=. Core scalar and array columns decode from PostgreSQL text format (binary result columns are rejected explicitly rather than guessed):

- Unknown types stay UTF-8 strings with their OID preserved.
- =numeric=, =date=, and wall-clock =timestamp= stay exact text; =timestamptz= decodes to an Emacs time value.
- =bytea= uses unibyte strings and accepts both PostgreSQL hex and escape formats.

** Transactions, errors, and cancellation

Both =pgsql-exec= and =pgsql-exec-params= read the full response through =ReadyForQuery= before returning or signaling. =pgsql-transaction-status= returns =idle=, =in-transaction=, or =failed-transaction= directly from that server message. Structured server errors signal =pgsql-server-error= (read fields like =:sqlstate=, =:detail=, and =:constraint= via =pgsql-error-fields=), and the connection stays reusable afterward. Any =NotificationResponse= received during a query is passed to =pgsql-notification-functions= with =(conn plist)= containing =:pid=, =:channel=, and =:payload=; idle connections are not polled.

=pgsql-cancel= sends PostgreSQL's CancelRequest over a short-lived auxiliary connection while the original query drains its cancellation error and final =ReadyForQuery=. Pressing =C-g= or hitting a read timeout during a synchronous query runs this cancel-and-drain flow automatically before re-signaling =quit= or =pgsql-timeout=; if resynchronization fails, the connection is closed.

** Asynchronous queries and COPY

=pgsql-exec-async= and =pgsql-exec-params-async= return =nil= immediately and invoke their callback once from a timer with =(result error)=. The connection stays busy until then. After a =pgsql-server-error= the connection stays reusable; any other error closes it. The read timeout does not apply to async queries; use =pgsql-cancel= to stop one.

#+begin_src emacs-lisp
(pgsql-exec-async
 conn "SELECT count(*) FROM big_table"
 (lambda (result error)
   (if error
       (message "Failed: %s" (error-message-string error))
     (message "Rows: %S" (pgsql-result-rows result)))))
#+end_src

For large results, =pgsql-exec-rows-async= delivers decoded batches as =pgsql-result= objects without holding all rows in memory, and still calls the final callback with column metadata and command tag even for empty results.

=pgsql-copy-out-async= streams =COPY ... TO STDOUT= in batches of unibyte row strings, invoking the consumer from a timer outside the process filter and waiting for each call to return before sending the next batch. If the consumer signals an error, the command is cancelled and the final callback receives that error once drained. (=COPY FROM STDIN= is not supported.)

#+begin_src emacs-lisp
(pgsql-copy-out-async
 conn "COPY (SELECT * FROM big_table) TO STDOUT (FORMAT csv, HEADER)"
 (lambda (rows)
   (with-temp-buffer
     (set-buffer-multibyte nil)
     (apply #'insert rows)
     (let ((coding-system-for-write 'no-conversion))
       (write-region nil nil "/tmp/big_table.csv" t 'silent))))
 (lambda (result error)
   (message "%s" (if error (error-message-string error)
                   (pgsql-result-command-tag result)))))
#+end_src

* Public API

Connections and results are opaque; use only the public =pgsql-*= symbols below (never =pgsql--*=):

- Connection lifecycle: =pgsql-connect= (=:database=, =:user=, =:password=, =:host=, =:port=, =:sslmode=, =:connect-timeout=, =:read-timeout=, =:application-name=), =pgsql-disconnect=, =pgsql-connection-p=
- Defaults and bounds: =pgsql-connect-timeout=, =pgsql-read-timeout=, =pgsql-sslmode=, =pgsql-application-name=, =pgsql-max-message-bytes=, =pgsql-set-connect-timeout=, =pgsql-set-read-timeout=
- Connection state: =pgsql-live-p=, =pgsql-busy-p=, =pgsql-transaction-status=, =pgsql-parameter=, =pgsql-user=, =pgsql-host=, =pgsql-port=, =pgsql-database=
- Execution and cancellation: =pgsql-exec=, =pgsql-exec-params=, =pgsql-exec-async=, =pgsql-exec-params-async=, =pgsql-exec-rows-async=, =pgsql-copy-out-async=, =pgsql-cancel=
- Results and columns: =pgsql-result-p=, =pgsql-result-columns=, =pgsql-result-rows=, =pgsql-result-command-tag=, =pgsql-result-affected-rows=, =pgsql-result-notices=, =pgsql-column-name=, =pgsql-column-type-oid=, =pgsql-column-type-name=, =pgsql-type-name=
- Values and quoting: =pgsql-null=, =pgsql-null-p=, =pgsql-array-literal=, =pgsql-escape-identifier=, =pgsql-escape-literal=
- Errors and hooks: =pgsql-error= (subtypes: =pgsql-connection-error=, =pgsql-timeout=, =pgsql-protocol-error=, =pgsql-authentication-error=, =pgsql-server-error=), =pgsql-error-fields=, =pgsql-notice-functions=, =pgsql-notification-functions=

* Development

Run the full non-live test and lint suite (no PostgreSQL server needed):

#+begin_src sh
./test/run-ci.sh all
#+end_src

Run the live PostgreSQL 16 suite (creates and drops one temporary login role to test non-ASCII SCRAM auth, so the configured user needs =CREATEROLE=):

#+begin_src sh
PGSQL_TEST_HOST=127.0.0.1 \
PGSQL_TEST_PORT=5432 \
PGSQL_TEST_USER=pgsql \
PGSQL_TEST_PASSWORD=pgsql \
PGSQL_TEST_DATABASE=pgsql_test \
./test/run-ci.sh live
#+end_src

Run the self-contained TLS test suite (spins up a temporary PostgreSQL 16 container with an ephemeral CA and cleans up on exit):

#+begin_src sh
./test/run-tls-live-tests.sh
#+end_src
